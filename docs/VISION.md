# Catalyzer 製品ビジョン

> **Last Updated**: 2026-01-27
> **Status**: Approved

---

## 1. 製品概要

**Catalyzer**は、Cataclysm: Dark Days Ahead (CDDA) 向けの**シンプルなMod管理ツール**。

### ターゲットユーザー
- 日本人CDDAプレイヤー
- MacOS/Windowsユーザー

### 競合との差別化
- **Catapult**: Windows専用 → Catalyzerは**MacOS対応**
- **手動管理**: 煩雑 → Catalyzerは**ワンクリック操作**

---

## 2. コアバリュー

### 最重視: シンプルさ
- 迷わず使える
- 状態が一目で分かる
- git知識不要

---

## 3. ユースケース

1. **Stable版で安定プレイ** - メインはStable、たまにExperimental確認
2. **Experimentalを追いかける** - 常に最新版で遊ぶ
3. **複数ワールド並行** - 異なるMod構成で複数プレイ
4. **Mod開発/テスト** - 自作Modの動作確認

---

## 4. 核心的な課題

### ゲームバージョン ⇔ Mod互換性
- Stable/Experimental間でModのJSON定義が変化
- Experimental間でも変化することがある
- **現在遊んでいるゲームバージョンにModが紐づく必要がある**

### 現状の問題
- 今どのProfile、どのMod構成を使っているか不明瞭
- 編集しづらい
- gitの複雑さがユーザーに負担

---

## 5. 設計方針

### Before（旧設計）
```
複雑なgit + プロファイル管理
  ↓
ユーザーが「ブランチ」「断面」を理解する必要
  ↓
操作が分かりにくい、状態が不明瞭
```

### After（新設計）
```
シンプルな「環境スナップショット」
  ↓
ゲームバージョンID + Mod構成 + 設定 = 1つの「状態」
  ↓
ワンクリックで保存・復元・切替
```

### gitについて
- **代替手段があれば不要**
- 内部実装としてgitを使う可能性はあるが、ユーザーには見せない

## 6. スナップショット設計

### 保存方式: フォルダコピー方式（B案）

**決定**: シンプルさを最優先し、フォルダコピー方式を採用。

```
snapshots/
├── snapshot_001_stable_ja/     # スナップショット1
│   ├── mods/                   # Mod一式（フルコピー）
│   ├── config/                 # 設定ファイル
│   ├── save/                   # セーブデータ
│   └── snapshot.yaml           # メタ情報
├── snapshot_002_exp_magic/     # スナップショット2
│   └── ...
└── snapshot_003_vanilla/       # スナップショット3
    └── ...
```

### 保存するもの

| 項目 | 保存方法 | 理由 |
|------|----------|------|
| ゲームバージョン | **IDのみ** | 再ダウンロード可能（容量節約） |
| Mod構成 | **フルコピー** | 確実な復元、シンプルな実装 |
| 設定ファイル | **フルコピー** | 確実な復元 |
| セーブデータ | **フルコピー** | 確実な復元 |

### データ構造

```yaml
# snapshot.yaml
snapshot:
  name: "Stable 0.I + 日本語Mod"
  created_at: "2026-01-27T10:30:00"

  game:
    version_id: "cdda-0.I-2026-01-20-1811"
    platform: "macos"

  # 以下は実フォルダとして保存（参照不要）
  # mods/     → フルコピー
  # config/   → フルコピー
  # save/     → フルコピー
```

### 容量見積もり

| 項目 | 1スナップショット | 10スナップショット |
|------|-------------------|---------------------|
| Mod | 50〜200MB | 500MB〜2GB |
| 設定 | 1〜5MB | 10〜50MB |
| セーブ | 10〜100MB | 100MB〜1GB |
| **合計** | **60〜300MB** | **600MB〜3GB** |

### 容量対策オプション

ユーザーが容量を気にする場合のオプション:

| 対策 | 効果 | 実装コスト |
|------|------|-----------|
| **古いスナップショット削除** | 即効性あり | 低（UIボタン） |
| **セーブデータ除外オプション** | 大幅削減 | 低（チェックボックス） |
| **Mod重複排除（将来）** | 中程度削減 | 高（ハッシュ管理） |

**優先実装**: 削除ボタン + 容量表示

## 7. 主要機能（新設計）

### A. 環境スナップショット
- **保存**: 現在のMod構成 + 設定をまとめて保存
- **復元**: ワンクリックで過去の状態に戻る
- **切替**: 複数の環境を簡単に切り替え

### B. 明確な状態表示
- ヘッダーに常時表示: 「Stable 0.I + Mod構成A」
- 視覚的な差分: 現在と保存状態の違いを表示

### C. かんたん編集
- Mod追加/削除: シンプルな操作
- 構成の名前変更: インライン編集
- 複製: 既存構成をベースに新規作成

### D. ゲームバージョン管理
- ダウンロード: Stable/Experimentalの取得
- バージョン切替: ゲームバージョンIDで管理
