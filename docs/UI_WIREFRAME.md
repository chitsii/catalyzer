> **バージョン**: 1.1.0
> **最終更新**: 2026-01-27
> **ステータス**: ドラフト

## 1. 現行UIの課題

### 1.1 状態が不明瞭

| 問題 | 詳細 |
|------|------|
| ゲームバージョン非表示 | 今どのバージョン（Stable/Experimental）で遊んでいるか分からない |
| Mod構成の全体像が見えない | 有効なModの数や状態が一目で分からない |
| プロファイル概念が曖昧 | 「プロファイル」がゲームバージョンとMod構成のどちらを指すのか不明確 |

### 1.2 git概念の露出

| 問題 | 詳細 |
|------|------|
| ブランチ・コミット概念 | ユーザーがgit知識を要求される設計 |
| 差分管理の複雑さ | 内部実装がUIに漏れている |

### 1.3 編集しづらい

| 問題 | 詳細 |
|------|------|
| 深いメニューネスト | プロファイル編集に3階層のドロップダウン |
| 操作の分散 | 関連操作が複数の場所に点在 |
| フィードバック不足 | 操作結果が分かりにくい |

## 2. 新UIの設計方針

### 2.1 コアコンセプト

```
┌─────────────────────────────────────────────────────────┐
│  「スナップショット」= ゲーム環境の"状態"               │
│                                                         │
│  ゲームバージョン + Mod構成 + 設定 = 1つのスナップショット │
└─────────────────────────────────────────────────────────┘
```

**保存方式**: フォルダコピー方式（B案）
- シンプルで確実な復元
- 容量は増えるが、管理が簡単

### 2.2 設計原則

| 原則 | 実現方法 |
|------|----------|
| **迷わず使える** | 主要操作は1クリック、最大2クリック |
| **状態が一目で分かる** | ヘッダーに常時表示、色分けで視覚的に区別 |
| **git知識不要** | 内部実装を完全に隠蔽、ユーザー向け用語のみ使用 |

### 2.3 用語の統一

| 旧用語 | 新用語 | 理由 |
|--------|--------|------|
| プロファイル | スナップショット | 「状態の保存」を直感的に表現 |
| ブランチ | （廃止） | git概念を排除 |
| コミット | （廃止） | git概念を排除 |

## 5. 状態遷移図

### 5.1 メイン画面遷移

```mermaid
stateDiagram-v2
    [*] --> メイン画面

    メイン画面 --> スナップショット一覧: タブ切替
    メイン画面 --> Mod一覧: タブ切替
    メイン画面 --> 設定: タブ切替

    スナップショット一覧 --> スナップショット詳細: 選択
    スナップショット詳細 --> スナップショット一覧: 戻る

    Mod一覧 --> Mod追加ダイアログ: 追加ボタン
    Mod追加ダイアログ --> Mod一覧: 完了またはキャンセル

    メイン画面 --> ゲーム起動中: 起動ボタン
    ゲーム起動中 --> メイン画面: ゲーム終了
```

### 5.2 スナップショット操作フロー

```mermaid
flowchart TD
    A[スナップショット一覧] --> B{操作を選択}
    B -->|切替| C[確認ダイアログ]
    C -->|はい| D[環境切替を実行]
    D --> E[ヘッダー表示を更新]
    E --> A

    B -->|複製| F[名前を入力]
    F --> G[新規作成]
    G --> A

    B -->|編集| H[編集画面]
    H --> I[保存]
    I --> A

    B -->|削除| J[確認ダイアログ]
    J -->|はい| K[削除を実行]
    K --> A
```

## 6. 操作フロー

### 6.1 スナップショット保存フロー

```
ユーザー操作                          システム動作
─────────────────────────────────────────────────────
1. [現在の状態を保存] をクリック
                                      → 保存ダイアログを表示
2. スナップショット名を入力
   例: "Stable + 日本語Mod"
                                      → 入力を検証
3. [保存] をクリック
                                      → 容量をチェック
                                      → 現在の状態を保存
                                        - ゲームバージョンID
                                        - Modフォルダをコピー
                                        - 設定フォルダをコピー
                                        - セーブフォルダをコピー
                                      → 一覧に追加
                                      → 完了通知を表示
```

### 6.2 スナップショット復元フロー

```
ユーザー操作                          システム動作
─────────────────────────────────────────────────────
1. スナップショット一覧で
   [切替] をクリック
                                      → 確認ダイアログを表示
                                        「〇〇に切り替えますか？」
2. [はい] をクリック
                                      → 現在の変更を確認
                                        （未保存の場合は警告）
                                      → 環境を復元
                                        - ゲームバージョンを確認/DL
                                        - Modフォルダを復元
                                        - 設定フォルダを復元
                                        - セーブフォルダを復元
                                      → ヘッダー表示を更新
                                      → 完了通知を表示
```

### 6.3 Mod追加/削除フロー

```
【追加】
ユーザー操作                          システム動作
─────────────────────────────────────────────────────
1. [+ 追加] をクリック
                                      → 追加方法選択ダイアログ
                                        - ZIPファイルを選択
                                        - フォルダを選択
                                        - ドラッグ&ドロップ
2. ファイル/フォルダを選択
                                      → Mod情報を解析
                                      → 互換性をチェック
                                      → Modフォルダにコピー
                                      → 一覧を更新
                                      → 「未保存の変更あり」を表示

【削除】
1. Mod一覧で [削除] をクリック
                                      → 確認ダイアログ
2. [はい] をクリック
                                      → Modを削除
                                      → 一覧を更新
                                      → 「未保存の変更あり」を表示
```

### 6.4 容量クリーンアップフロー

```
ユーザー操作                          システム動作
─────────────────────────────────────────────────────
1. [🧹 クリーンアップ] をクリック
                                      → クリーンアップダイアログを表示
                                        - 全スナップショットを容量順に表示
                                        - 現在使用中は削除不可
2. 削除したい項目にチェック
                                      → 削除予定容量を計算して表示
3. [削除] をクリック
                                      → 確認ダイアログ
4. [はい] をクリック
                                      → 選択したスナップショットを削除
                                      → 容量表示を更新
                                      → 完了通知を表示
```

## 7. 比較表: 現行UI vs 新UI

| 観点 | 現行UI | 新UI |
|------|--------|------|
| **状態表示** | プロファイル名のみ | ゲームVer + Mod数 + 変更状態 + 容量 |
| **主要操作** | 3階層ドロップダウン | 1クリック |
| **用語** | プロファイル、ブランチ | スナップショット |
| **git概念** | 一部露出 | 完全隠蔽 |
| **ゲーム起動** | メニュー内 | ヘッダーに常時表示 |
| **Mod管理** | テーブル表示 | テーブル + 状態表示 |
| **編集操作** | ネストメニュー | インライン + ダイアログ |
| **フィードバック** | 少ない | 状態変化を明示 |
| **容量管理** | なし | 使用量表示 + クリーンアップ |
